# 个人图书库

这是一个可直接用 [Obsidian](https://obsidian.md/) 打开的个人蒸馏图书库。它不把读书停在摘要或摘录，而是把内容转化为可判断、可迁移、可执行、可验证的认知资产。所有内容均为标准 Markdown；即使未安装第三方插件，也能正常使用。

## 快速开始

1. 在 Obsidian 中选择“打开本地仓库”，打开本目录。
2. 打开 [[00-首页]]，从“书籍模板”新建第一本书。
3. 阅读后使用 [[99-模板/蒸馏模板|蒸馏模板]]：从现象、逻辑、规则走到行动，并写清边界与验证方法。
4. 把书籍页面放在 `01-书籍/`，蒸馏笔记放在 `02-阅读笔记/`，必要的短摘录放在 `03-摘录/`。
4. 在 [[04-阅读目标/2026-阅读目标]] 维护年度目标与进度。
5. 定期提交并推送 Git 变更，以同步到其他设备。

## 蒸馏原则

> 摘要让人“知道”，蒸馏让人“会用”。

一份完成的蒸馏应包含：核心命题、因果或结构、判断规则、行动清单、适用边界和验证方式。不要把金句、摘抄或“我觉得很有道理”当作蒸馏完成。

仓库内的 [knowledge-distillation Skill](skills/knowledge-distillation/SKILL.md) 将这套方法写成了可复用的 AI 工作规则。

## Obsidian 设置建议

- 开启核心插件“模板”，模板文件夹设为 `99-模板`。
- 开启核心插件“日记”或“周期性笔记”（可选），把阅读记录模板设为 `99-模板/阅读记录模板.md`。
- 附件默认存入 `05-附件`；书籍封面建议使用外链，避免仓库膨胀。

## Git 同步

```bash
git add .
git commit -m "更新阅读记录"
git push
```

此仓库目前为公开仓库。请不要提交私人摘录、账号信息、购买记录或受版权限制的大段内容；如未来要保存私密笔记，请先将仓库设为私有。
